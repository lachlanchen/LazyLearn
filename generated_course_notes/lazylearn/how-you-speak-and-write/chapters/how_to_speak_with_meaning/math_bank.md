## Definitions And Objects
- `\text{@}`: central node in the audience-layout figure; visually a source or transmission marker, semantically clarified by the transcript.
- `\text{human layer}`: the live, embodied component that a talk adds beyond printed words.
- `\text{inspiration}`: the lecture’s name for the activated state in which an idea captures attention instead of being forgotten.
- `\text{voice}`: one of the two principal variables in talk preparation.
- `\text{body}`: the second principal variable in talk preparation.
- `\underline{\text{important word}}`: sentence-level emphasis mark.
- `\underline{\underline{\text{paragraph key word}}}`: stronger paragraph-level emphasis mark.
- `\text{wavy underline}`: notation for light, playful, or quickened delivery.
- `\text{black blob}`: pause marker placed before the talk’s main aha moment.
- `\text{pink dots}`: humor marker; cue for lightness or laughter.
- `=` between the legs: balance notation in the posture figure.
- `\times` / `\checkmark`: contrasting endpoint symbols in the decision-tree figure.
- `\text{rocking}`: unwanted back-and-forth bodily rhythm signaling discomfort.
- `\text{stillness}`: deliberate stopping used to add emphasis and control.

## Derivation Steps
**1. Live talk versus emailed script**
1. Begin from the fact that a script can already contain the words.
2. Ask why one should speak rather than merely send the text.
3. Answer that talks can offer something beyond printed words.
4. Name that extra term as humanity.
5. Conclude that live delivery is justified when it adds a human layer that changes reception.

**2. Humanity to inspiration**
1. List the listener-side effects: trust, interest, heard emphasis, empathy, excitement, conviction, action.
2. Treat these not as separate ornaments but as converging effects.
3. Compress them into a single outcome: inspiration.
4. Contrast inspired reception with ideas that are merely filed away.
5. Conclude that humanity transforms information into inspiration.

**3. Inspiration to the two-variable split**
1. Define inspiration functionally as what tells the mind what to do with a new idea.
2. Ask what we can actually control in preparing a talk.
3. Split the problem into two major considerations.
4. Identify them from the transcript as voice and body.
5. Use that split to organize the rest of the lecture.

**4. Monbiot example to vocal rule**
1. Listen to a speaker whose words feel unusually alive.
2. Observe that the effect is not only in the words but in the saying of them.
3. Ask how that effect is produced.
4. Reject the monotone case where every sentence sounds the same.
5. State the rule: vocal variety must track meaning.
6. Conclude that voice adds semantic force when its variation is content-driven.

**5. Script-marking algorithm**
1. Start with the written script.
2. Mark the two or three important words in each sentence.
3. Mark the one dominant word in each paragraph more strongly.
4. Add special marks for questions, playful stretches, jokes, and the main aha moment.
5. Read the script again while changing the voice in response to those marks.
6. Conclude that markings externalize a delivery plan.

**6. Emotional second pass**
1. Return to the script after the first marking pass.
2. Identify the emotion attached to each section: passion, anger, laughter, confusion, and so on.
3. Read again while letting those emotions enter the voice slightly.
4. Test the result with a friend or a recording.
5. Conclude that vocal variety should come from felt meaning, not artificial performance.

**7. Body-stability algorithm**
1. Begin from the awkward-body failure state.
2. Replace it first with a stable stance.
3. Put equal weight on both feet.
4. Let the upper body and hands move naturally.
5. Use movement only with purpose.
6. Stop moving when emphasis is needed.
7. Conclude that body control is rhythmic, not rigid.

**8. Movement versus rocking**
1. Notice that some speakers walk the stage.
2. Observe that walking works only when broken by stillness.
3. Contrast that with nervous rocking or constant pacing.
4. Note that the latter makes discomfort visible to the audience.
5. Conclude that stillness and movement are tools only when they have intention.

## Notation Choices
- Use `\Longrightarrow` for pedagogical implication and causal-explanatory flow.
- Use `\neq` for lecture-level contrasts such as script alone versus live talk.
- Use `+` only for genuinely combined ingredients, such as humanity plus information.
- Use `\mapsto` for markup conventions that translate visual marks into delivery instructions.
- Keep most symbolic content inside `\text{...}`; this lecture is procedural, not algebraic.
- Preserve the visible symbols `\text{@}`, `\text{?}`, `\times`, `\checkmark`, `\underline{\cdot}`, and `=` when they are actually seen in the figures.
- Prefer written phrases such as `\text{weight on left foot}` over compressed variables like `w_L` unless a later draft explicitly wants shorthand.
- Treat the decision-tree figure as structural notation, not as a fully specified logical diagram.
- Treat the paragraph-marking figure as abstract markup notation, not as a transcription of actual words.
- Keep the audience-layout figure radial and unlabeled except for the central `@`, unless the surrounding prose supplies the meaning.
- Use braces only for schematic grouping, e.g.
  \[
  \text{talk preparation} \Longrightarrow \{\text{voice},\text{body}\}.
  \]
